# Data Directory

This directory stores data generated by the SustainAds AI application.

## Contents

- **generations.log**: Log of all video generations with timestamps
- **analytics/**: Analytics data for video performance
- **user-data/**: User business information (when applicable)
- **exports/**: Exported data and reports

## Structure

```
data/
├── generations.log       # Video generation logs
├── analytics/           # Performance metrics
├── user-data/          # Business data storage
└── exports/            # Data exports
```

## Privacy & Security

- This directory may contain sensitive business information
- Add to `.gitignore` to prevent committing sensitive data
- Implement proper access controls in production
- Regular backups recommended
- Follow GDPR and data protection guidelines

## Usage

The application automatically creates and manages files in this directory. Manual intervention is typically not required.
